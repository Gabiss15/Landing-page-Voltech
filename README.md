
# ⚡ Voltech EJ — Website Oficial & Plataforma

Bem-vindo ao repositório oficial da **Voltech EJ**. Este projeto contempla a landing page institucional da empresa e, em breve, a nossa plataforma interna de gestão de membros, clientes e projetos.

---

## 📌 Status do Projeto

* 🟢 **Fase 1 — Landing Page:** Publicada e ativa.
* 🚧 **Fase 2 — Plataforma Interna (Área de Membros & Clientes):** ⚙️ *Em construção / desenvolvimento*.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **Frontend:** [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Animações:** [Framer Motion / Motion](https://motion.dev/)
- **Hospedagem:** [Vercel](https://vercel.com/)
